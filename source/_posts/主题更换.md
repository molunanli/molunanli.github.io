## 检查本地的博客项目是否全部提交
```git
git status
```
出现下面说明已经全部提交
```git
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
```
## 添加子模块
接下来我们需要把写好的主题添加做博客项目的子模块,在博客项目根目录下执行命令
```git
git submodule add https://github.com/molunanli/zzz_theme.git themes/zzz_theme
```
https://github.com/molunanli/zzz_theme.git 是我自己写的一个hexo博客主题。
```themes/zzz_theme```这里是指在博客项目的themes目录下，博客主题名称(也就是文件夹名称)为zzz_theme
成功后提示

电脑本地的博客项目出现文件夹```my-blog/themes/zzz_theme```
接下来修改本地博客项目的配置文件```my-blog/config.yml```
```bash
theme: zzz_theme
```
最后提交github
## 更新子模块
然后当我们的主题更新后，我们需要在博客项目拉取所有子模块的最新远程更新
```bash
git submodule update --remote
```
这个命令会进入子模块目录，拉取远程仓库的最新代码，并将主仓库记录的 Commit ID 更新为最新的。
